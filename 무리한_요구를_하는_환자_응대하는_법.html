무리한 요구를 하는
환자 응대하는 법

병원 규정과 기준을 지키면서도
환자가 불쾌함 없이 받아들일 수 있도록
상황별 응대 멘트를 정리한 가이드입니다.

📌 응대의 3가지 핵심 원칙
  • 1
    감정이 아닌 기준이 말하게 한다. 직원 개인이 거절하는 게 아니라, 병원의 운영 기준을 전달하는 것입니다. "제가 어떻게 할 수 없어서"가 아니라 "저희 병원 기준이 이렇습니다"라는 구도를 유지하세요.
  • 2
    기준은 분명하게, 전달은 부드럽게. "무조건 안 됩니다" 대신 "저희 원내 규정은 이렇습니다"로 표현합니다. 기준 자체는 절대 흐리지 않되, 환자가 존중받는 느낌을 받을 수 있도록 톤을 유지하세요.
  • 3
    모든 직원이 같은 말을 한다. 어느 직원에게 물어봐도 같은 답변이 돌아와야 일관된 응대를 할 수 있고, 환자가 기준을 자연스럽게 받아들이게 됩니다.
상황별 응대 멘트
🗓️
치료 순서 · 대기 기준 안내
대기 순서 변경, 먼저 해달라는 요청
상황 예시
대기 순서를 바꿔달라는 요청 / 자신을 먼저 치료해달라는 요청 / 자신이 먼저 왔다며 항의하는 경우
"앞에 대기 중이신 분들이 계셔서, 순서대로 진행해드리겠습니다. 양해 부탁드립니다."
순서나 대기 관련 요청은 "시스템 기준"임을 앞에 두면 직원 개인의 결정처럼 보이지 않습니다.
⏱️
치료 시간 · 방법 변경 요청
감당하기 어려운 무리한 요구가 반복될 때
상황 예시
가능한 범위를 넘어서 반복적으로 더 요구하는 경우 / 치료 방법을 자꾸 바꿔달라고 하는 경우 / 다른 환자와 비교하며 더 해달라고 요구하는 경우
"가능한 부분은 최대한 맞춰드리고 있는데, 이 부분은 저희 기준상 어렵습니다."
→ 배려하고 있다는 점을 먼저 전달하고, 한계를 짧게 정리
"치료 방식은 원장님 처방 기준에 따라 진행되고 있어서, 제가 임의로 변경하기가 어렵습니다."
→ 직원이 아닌 의료 기준이 말하는 구도
"모든 분께 동일한 기준으로 진행하고 있어서, 이 부분은 어렵습니다. 양해 부탁드립니다."
요구가 적절한 범위 안에 있을 때는 유연하게 대응하되, 반복적이거나 무리한 요구가 이어질 때 이 멘트를 활용하세요.
🙏
규정 외 편의 · 특별 대우 요청
예외 처리, 기준 외 배려 요청
상황 예시
"저번엔 됐는데 왜 이번엔 안 되냐" / "한 번만 봐달라" / 특정 직원에게만 반복적으로 요청하는 경우
"이전에 다르게 안내됐다면 혼선이 있었던 것 같습니다. 현재 저희 기준으로는 이렇게 운영되고 있습니다."
→ 과거 사례를 인정하되, 현재 기준으로 자연스럽게 돌아옴
"한 분께만 예외를 드릴 수가 없어서 다른 분들께도 동일하게 저희가 기준을 맞추고 있습니다. 양해해 주시면 감사하겠습니다."
"다른 분들도 동일하게"라는 표현은 '당신만 거절하는 게 아니다'는 메시지를 자연스럽게 전달합니다.
😤
불만 · 항의 상황 응대
언성을 높이거나 반복적으로 따지는 경우
상황 예시
"말이 되냐"며 언성을 높이는 경우 / 같은 항의를 계속 반복하는 경우 / 직원 개인을 지목해 따지는 경우
"불편하게 느끼셨다면 죄송합니다. 제가 드릴 수 있는 안내는 앞서 말씀드린 내용과 같습니다."
→ 공감으로 시작하되, 기준은 그대로 유지. 추가 협상 여지를 두지 않습니다
"제가 혼자 판단하기 어려운 부분이라, 확인 후 다시 안내드릴게요. 잠시만 기다려 주시겠어요?"
→ 혼자 감당하려 하지 말고 즉시 윗선에 공유하세요
항의가 반복되더라도 흔들리지 말고 차분하게 같은 기준을 유지하세요. 톤이 일정할수록 상황이 빠르게 정리됩니다.
🔄
반복 민원 · 누적 관리 환자
매번 예외를 요구하거나 계속 문제가 생기는 경우
상황 예시
방문할 때마다 규정 외 요구 반복 / 직원들에게 번갈아 같은 요청 / 여러 차례 안내 후에도 지속
"안내드린 대로, 기준에 따라 응대해 드리는 점 양해 부탁드립니다."
"여러 차례 동일하게 안내를 드렸는데, 이 부분은 저희 운영 기준상 변경이 어렵습니다."
같은 요구가 반복되는 경우, 혼자 감당하려 하지 마세요. 여러 직원이 상황을 공유하고, 필요하면 상부 또는 원장님과 함께 대응하는 것이 훨씬 효과적입니다.

응대 시 마음가짐
✅ 기억하세요
  • 기준을 안내하는 것은 직원의 당연한 역할입니다
  • 미소와 차분한 톤은 기준을 지키면서도 유지할 수 있습니다
  • 짧고 일관되게 반복하는 것이 가장 효과적입니다
  • 혼자 해결이 어려우면 즉시 윗선에 공유하세요
  • 모든 부서가 같은 말을 해야 환자도 받아들입니다
❌ 피하세요
  • 긴 설명과 지나친 사과 — 여지를 줍니다
  • 감정적으로 반응하거나 방어적으로 대응하기
  • 직원 개인의 판단으로 예외 허용하기
  • 부서마다 다른 기준과 답변 제공하기
  • 어려운 상황을 혼자 감당하려 하기
